# 📜 Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/en/2.0.0/).

## [2.0.0] - 2025-01-20

### ✨ Added
- **Personalized Music Recommendations**: MP3 archive analysis to identify top artists.
- **Oscar Soundtrack Integration**: All Oscar winners in the "Best Original Score" category.
- **Guides Category**: The best non-fiction guides of the 21st century.
- **Intelligent Blacklist System**: Permanently saves media without library matches.
- **Source Tracking System**: Emoji-based identification of all recommendations.
- **AI-Powered Google Search**: Automatic summaries via Groq.

## [1.0.0] - 2024-12-01

### ✨ Added
- **Core Functionality**: Film recommendations, music recommendations, book recommendations.
- **Availability Check**: Integration with Cologne City Library.
- **Interactive GUI**: Gradio-based user interface.
- **Markdown Export**: Save recommendations to `recommended.md`.
