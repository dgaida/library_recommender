## 🤝 Code of Conduct

This project follows a Code of Conduct based on the Contributor Covenant.

## 🚀 How Can I Contribute?

### 🐛 Bug Reports

Create a GitHub issue with a clear description of the problem.

### 💡 Feature Requests

We love new ideas! Create an issue and describe your desired feature.

### 💻 Code Contributions

1. Fork the repository.  
2. Create a feature branch.  
3. Run tests.  
4. Create a pull request.  

## 🛠️ Development Setup

```bash
pip install -r requirements.txt
pip install -r requirements-dev.txt
```

## 📐 Coding Guidelines

- Use Black for code formatting.  
- Write docstrings in Google style.  
- Use type hints.  

## 🧪 Testing

```bash
pytest tests/ -v
```
