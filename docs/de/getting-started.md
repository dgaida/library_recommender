# 🏁 Schnellstart

Dieser Guide zeigt Ihnen, wie Sie die App schnell zum Laufen bringen.

## 1. Voraussetzungen

- Python 3.9+
- Internetverbindung (für Bibliotheks-Suche)
- Optional: Groq API Key für KI-Zusammenfassungen

## 2. Installation

Installieren Sie die notwendigen Abhängigkeiten:

```bash
pip install -r requirements.txt
```

## 3. App starten

Starten Sie die App:

```bash
python main.py
```

Öffnen Sie `http://localhost:7860` in Ihrem Browser.
