# 📜 Änderungshistorie

Alle wichtigen Änderungen an diesem Projekt werden in dieser Datei dokumentiert.

Das Format basiert auf [Keep a Changelog](https://keepachangelog.com/de/1.0.0/),
und dieses Projekt folgt [Semantic Versioning](https://semver.org/lang/de/).

## [2.0.0] - 2025-01-20

### ✨ Hinzugefügt
- **Personalisierte Musikempfehlungen**: Analyse des MP3-Archivs zur Identifikation von Top-Interpreten.
- **Oscar-Filmmusik Integration**: Alle Oscar-Gewinner der Kategorie "Beste Filmmusik".
- **Ratgeber-Kategorie**: Die besten Ratgeber des 21. Jahrhunderts.
- **Intelligentes Blacklist-System**: Speichert Medien ohne Bibliotheks-Treffer dauerhaft.
- **Quellen-Tracking System**: Emoji-basierte Kennzeichnung aller Empfehlungen.
- **KI-gestützte Google-Suche**: Automatische Zusammenfassungen mit Groq.

## [1.0.0] - 2024-12-01

### ✨ Hinzugefügt
- **Grundfunktionalität**: Filmempfehlungen, Musikempfehlungen, Buchempfehlungen.
- **Verfügbarkeitsprüfung**: Integration mit Stadtbibliothek Köln.
- **Interaktive GUI**: Gradio-basierte Benutzeroberfläche.
- **Markdown-Export**: Speichern von Empfehlungen in `recommended.md`.
