## 🤝 Code of Conduct

Dieses Projekt folgt einem Code of Conduct basierend auf dem Contributor Covenant.

## 🚀 Wie kann ich beitragen?

### 🐛 Bug Reports

Erstellen Sie ein Issue auf GitHub mit einer klaren Beschreibung des Problems.

### 💡 Feature Requests

Wir freuen uns über neue Ideen! Erstellen Sie ein Issue und beschreiben Sie Ihr gewünschtes Feature.

### 💻 Code Contributions

1. Forken Sie das Repository.  
2. Erstellen Sie einen Feature-Branch.  
3. Führen Sie Tests aus.  
4. Erstellen Sie einen Pull-Request.  

## 🛠️ Development Setup

```bash
pip install -r requirements.txt
pip install -r requirements-dev.txt
```

## 📐 Coding Guidelines

- Verwenden Sie Black für die Code-Formatierung.  
- Schreiben Sie Docstrings im Google-Style.  
- Verwenden Sie Type-Hints.  

## 🧪 Testing

```bash
pytest tests/ -v
```
